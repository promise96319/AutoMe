# Diff 展示规范

当用户要求查看 diff、对比修改前后，或查看具体改了哪些行时，直接展示实际差异。

1. **确定对比范围。** 用户指定了文件、提交或暂存区时，按指定范围比较。只说“看看当前改动”时，展示从最近一次提交到当前工作区的净变化，包含已暂存、未暂存的修改，以及未被 Git 忽略的新文件。
2. **按文件展示。** 优先使用当前界面的原生 diff 视图，像在 Cursor 中审阅改动一样，显示文件路径、行号和相邻上下文。删除行标红，新增行标绿。替换一段内容时，将旧段与新段放在同一处对照。
3. **在聊天中展示。** 界面无法直接呈现原生 diff 时，以文件路径为标题，下面放标准 `diff` 代码块。保留真实的 `@@` 行号、以空格开头的上下文行、以 `-` 开头的删除行和以 `+` 开头的新增行。纯重命名列出旧路径与新路径，二进制文件标明变更状态。
