# 走查 SKILL.md

走查写好的 SKILL.md 时，逐项完成以下检查，确认两件事：正文忠实于流程图；AI 只拿到正文时，能按流程图执行。

## 1. 走查项目

- [ ] **对照流程图**：逐步核对每个步骤、分支和去向都能在正文中找到，并且正文里没有图上没有的路径。
- [ ] **实际执行**：只把 SKILL.md 和实例的输入交给子代理执行，观察它走的路线和结果是否符合流程图；没有子代理时，自己只看正文逐步推演。
- [ ] **触发检查**：只看触发描述，判断实例应该触发；再用一个相近但不该触发的请求，确认不会被误触发。
- [ ] **修订时的复现检查**：用复现请求确认原来的问题不再出现。
- [ ] **修订时的回归检查**：用一个与改动无关的请求，确认原有行为没有被破坏。

## 2. 交给子代理时

- 只提供 SKILL.md 的路径和实例的输入，不附流程图、预期结果或你的推理，否则测不出正文本身是否够用。

## 3. 走查结果

走查结果列出每个走查项目是否通过；没有通过的，写明出现在哪一步、实际怎么走的、和流程图有什么不同。
