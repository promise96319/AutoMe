# 写成 SKILL.md

把用户确认的流程图 `skill-workflow.html` 写成 SKILL.md 时，按以下规则转换，不得增加流程图上没有的步骤、分支或去向。

- **以导出的文字版为初稿。** 流程图的“文字版”已按 SKILL.md 的格式排好，只做串联和措辞整理。
- **SKILL.md 依次包含三部分。** frontmatter 中的 `name` 和 `description` 取自流程图顶部；开头一段说明这个 skill 做什么、交付什么，有全局约束时紧接着写在“约束：”下面；最后是“工作流”，步骤编号与流程图一致。
- **正文与流程图保持一致。** 修改正文时，同步修改 `skill-workflow.html` 中的流程数据。
