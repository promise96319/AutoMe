create-skill 执行流程

create-skill 自己怎么工作：从收到“新建或修订一个 skill”的请求，到交付目标 skill。流程图和工作流文本由同一份数据生成，切换视图可以对照。

每个步骤都是同一个结构

  • 输入 → 编号动作 ①②③（可以直接执行的指令）→ 产出
  • 动作里的 条件 是分支；内容 是等用户回复，回复不同就走不同分支
  • 分支要么留在步骤内（如“回到 ①”），要么得出一个结果标签 标签
  • 步骤底部的“结果”列出这一步所有可能的标签和去向

颜色与位置

继续 进入下一步或子步骤 回退 回到前面的步骤 转到 改走另一条路径 提前结束 正常地提前结束 终止 异常结束
主线回退转到终止

离开主线的标签（回退、转到、提前结束、终止）会汇总到右侧“分支结果”列，并与产生它的结果行对齐。右栏“约束”只放不改变走向的要求；会改变走向的规则已经写成动作里的条件。
