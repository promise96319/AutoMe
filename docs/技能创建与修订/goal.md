# 1 `create-skill` 首版目标

交付一个用于创建和修订 skill 的 `create-skill`。给定新需求或已有 skill，它应能指导作者明确适用场景，画出目标 skill 的主流程，再把流程写成 Agent 可以执行的指令。首版通过修订现有的 `fix-bug` 验收。

## 1.1 首版范围

1. **明确何时使用。** 名称采用“动词原形 + 对象”，如 `create-skill`、`fix-bug`。`description` 沿用 `developing-skills` 的触发描述规则，用第三人称说明适用场景，推荐写成“当用户……时使用”。执行方法写在正文中。
2. **先画主流程，再写执行指令。** 从一个实际输入出发，画清主要动作、影响去向的判断和最终结果。按图编写正文，交代执行所需的输入、动作产生的结果，以及根据结果进入哪一步。流程涉及等待或重试时，写清恢复位置与结束条件。
3. **在规则生效处补充必要约束。** 每条细节规则都应能对应一个已遇到的问题，或一项必须遵守的明确要求。修订已有 skill 时，将规则融入受影响的步骤。例如，若要解决修复后漏验原问题的情况，就在验证步骤写明按原触发条件复测。

`references/` 和 `scripts/` 的拆分规则留待后续迭代。

## 1.2 验收标准

用 `create-skill` 修订 `fix-bug`，再选取一个具体缺陷场景。只看修订后的触发描述，就能判断该请求是否适用。沿流程图能从缺陷现象走到验证结果，并能在正文中找到各关键判断的依据、应执行的动作及其去向。
